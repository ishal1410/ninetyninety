# NinetyNinety vs. Agents for Humans: requirement-by-requirement fit audit

Audited 2026-09-06. Sources: live fetches of the Devpost pages listed under each row (WebFetch plus `curl` of the raw HTML, stripped locally), the two prior verified notes (the 2026-09-05 Agents for Humans verification note (kept outside the repo), `docs/research/2026-09-06-model-provider-rules.md`), and the repo at commit `bcf438b` (pushed to https://github.com/ishal1410/ninetyninety, `gh repo view`: `"visibility":"PUBLIC"`, `"licenseInfo":{"key":"mit"}`). Repo citations are `path:line`. Participant count on the site today: 7,913 (main page nav; was 7,754 on 09-05).

## TL;DR

1. **Theme fit: PASS.** Main page theme is "an AI agent with the Strands Agents SDK that handles routine and repetitive tasks in the background"; the project turns a raw bank CSV into a drafted Form 990-EZ Part I end to end (`README.md:3`, `src/ninetyninety/prepare.py:91-123`). It does not run "in the background" or "only surface when there's a real decision to make"; it is invoked per ledger, but it does surface only disagreements/low-confidence rows for the human (`prepare.py:55-71`).
2. **Good Neighbor Agents fit: PASS.** Track definition: "an agent that helps groups of people, not just one, neighborhoods, nonprofits, food banks, schools, libraries, small local orgs" (main page); resources page: "usually run by volunteers and tiny teams stretched thin ... helping a small nonprofit answer questions and coordinate events without a full-time coordinator". User = "Volunteer treasurers of small US nonprofits" (`README.md:13`). FAQ tiebreak "who the primary user is": a nonprofit, i.e. a group.
3. **Stage One as worded ("reasonably fits the theme and reasonably applies the required tools/APIs/SDKs"): PASS on paper.** `from strands import Agent` (`src/ninetyninety/agents.py:13`), `Agent(model=..., system_prompt=...)` x2 (`agents.py:70-75`), `strands-agents[gemini,openai]==1.54.0` (`requirements.txt:1`), named in README line 5, app.py line 3/24, GitHub description.
4. **Row count: 19 PASS, 7 GAP, 3 UNKNOWN** (29 rows; the Testing row counted as PASS for eligibility).
5. **Single biggest gap: no working demo has ever run.** `.env` is 0 bytes; `.superpowers/sdd/progress.md:31` "Step 6 LIVE CLI RUN BLOCKED: no GOOGLE_API_KEY in .env"; `:30` "no live model call yet"; `:33` "DEPLOY BLOCKED". Without a live model call there is no video, no live demo link, and the Strands usage is two `Agent(...)` constructors with zero tools (grep `tools|@tool|GraphBuilder` over `src/`, `app.py`, `cli.py`: no hits), which bears directly on criterion 1 ("How thoroughly and skillfully does the project use Strands Agents?") and the FAQ diagram spec ("model → tools → reasoning → response").
6. Second-order gaps: video, live demo URL (`README.md:54` placeholder), 3 blog posts, Devpost text description, AWS account (`progress.md:19` "NOT YET CREATED"), and an untracked 0-byte file `You` at repo root (`git status`: `?? You`).

## Things the organizers said judges want (verbatim)

- https://agentsforhumans.devpost.com/updates/46174-pro-tips-for-your-project: "Explain what your project does, who it's for, and how it works — plain language, not just a feature list." / "Lead with the problem. Could a judge tell what you built just from this plus your video?" / "Name Strands Agents explicitly — it's one of the first things reviewed." / "MIT or Apache license visible in the About section — an actual license file, not just a README mention." / "Setup instructions good enough that a stranger could get it running cold." / "AI coding assistants are explicitly allowed — use them for boilerplate, tests, debugging, whatever speeds you up." / "Writing new code with an assistant during the Submission Period is fine; reusing an old AI-built project isn't." / "Don't let AI overstate your pitch. Judges aren't required to test your project and may score based only on your text description, images, and video." / "Verify before you rely on it. AI tools hallucinate APIs with confidence — test what you plan to show in your demo ahead of time."
- https://agentsforhumans.devpost.com/updates/45987-how-to-actually-stand-out-in-agents-for-humans: "Solve a real, specific problem. The strongest projects target one concrete pain — a bill about to go late, a shift a food bank can't fill, a teacher turning one lesson into materials for thirty students. A clear, real problem lands better than a clever demo." / "Make it do real work — not just chat. The brief asks for an agent that handles something end to end. The best Everyday Agents run in the background and only surface when a human actually needs to decide something." / "Make your use of Strands Agents impossible to miss. Name it in your project description, add it to your 'Built With' section, and show it clearly in your demo video." / "Protect your API keys. A public repo with an exposed key is an open invitation to run up charges on your account. Use environment variables or a secrets manager, and scan your repo before you submit." / "Treat your video like a pitch, not a tutorial. You've got five minutes. Lead with the problem, show the solution working, and cover: what problem you're solving / who it's for / why it matters." / "Grab the bonus points. Publish a post on builder.aws.com about your build journey with 'Agents for Humans' in the title before the deadline."
- https://agentsforhumans.devpost.com/updates/45850-time-to-plan-your-agents-for-humans-project: "Start with the person, not the tech. Write one sentence: '[Who] is stuck doing [what], over and over.'" / "Pick ONE workflow and go end-to-end. Judges reward a single thing that fully works over five things that half work. Scope down before you scope up." / "Build the ugly version first. A working agent with zero polish beats a beautiful mockup that doesn't run." / "Storyboard your demo video now, not the night before. You've got 5 minutes: problem → who it's for → why it matters → it working." / "Building for a group of people coordinating together? → Good Neighbor Agents" / "Final day (Sept 14): Submit before 5:00 pm PT (aim for 3-4 hours before if you can!)." / "you can save a draft submission and keep editing it right up until the deadline."
