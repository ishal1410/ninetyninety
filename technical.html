How NinetyNinety is built.

One Strands Agents graph per batch of twelve bank rows. Two blind entry nodes, a conditional Referee, and Python for every sum. This page is for engineers and judges. The product page is for treasurers.

The graph.

Preparer and Reviewer are parallel entry nodes of a GraphBuilder graph; Strands hands each only the rows. Both call the real line_guidance tool and answer with pydantic structured output. The Referee hangs off a conditional edge and runs only on a disagreement.

input

Bank export

Date, description, amount. Batches of twelve go into the graph.

entry node, parallel

Preparer

Posts each row to a Part I line and quotes the IRS instruction through the line_guidance tool.

entry node, parallel, blind

Reviewer

Same job, never sees the Preparer. Agreement posts the row. Disagreement escalates.

conditional node

Referee

Runs only on a split. Reads both quoted rules, decides, and its reason is kept with the row.

python, no model

Foot and fill

Sums lines 9, 17, 18, checks every quoted rule against the IRS text, fills the PDF, stamps DRAFT.

Architecture diagram and source: docs/architecture.png, the repository. Model host: Google Gemini through the Strands GeminiModel, rotating model ids when a free-tier cap is hit. Amazon Bedrock is a one-line swap.
